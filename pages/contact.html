FAQ

How does repoIQ analyze my code?

repoIQ uses LLM and other advanced AI algorithms, compiler techniques to analyze code for performance, quality, and security issues. Our AI examines code patterns, identifies potential bottlenecks, and provides actionable recommendations without requiring code execution or profiling.

Is my code secure and private?

Yes, your code is encrypted in transit and at rest. We follow industry-standard security practices including SOC 2 compliance. Your code is never shared with third parties and is processed in secure, isolated environments.

What programming languages are supported?

Currently supported: C, C++, Java, Kotlin, Objective-C, and Objective-C++. We're actively adding support for Python, JavaScript, TypeScript, Go, and Rust.

How do I integrate repoIQ with my repository?

Simply connect your GitHub repository with one click. repoIQ automatically analyzes your codebase and provides detailed reports. You can also integrate with CI/CD pipelines using our API or GitHub Actions.

What types of issues does repoIQ detect?

Performance bottlenecks, logical bugs in code, inefficient algorithms, and some potential security vulnerabilities

How accurate are the analysis results?

Our AI models are trained on millions of code patterns and achieve over 95% accuracy with minimal false positives. Results are prioritized by impact and confidence levels to help you focus on the most critical issues first.

Can I use repoIQ for large codebases?

Yes, repoIQ scales to analyze codebases of any size, from small projects to enterprise applications with millions of lines of code. Analysis time scales efficiently with parallel processing capabilities.

Do you offer on-premise deployment?

Yes, we offer both cloud and on-premise deployment options. Enterprise customers can deploy repoIQ within their own infrastructure for maximum security and compliance requirements.

What support options are available?

We provide email support for all users, priority support for paid plans, and dedicated support engineers for enterprise customers. Documentation, tutorials, and community forums are also available.
